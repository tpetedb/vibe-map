- The board room and the shared memory for every agent session. `tools/board.py` reads and appends the room in the git common dir under a lock, with stable entry ids, checked-out and landed orders derived from `tools/work.py`, and explicit slots. `just board`, `just board-say`, `just board-slot` and `just memory-lint` wrap it.
- The memory is `memory.jsonl` next to the room plus a derived `index.json` (id, order, topic, owner, status, next action), with no memory server: `board.py memory add` appends an observation and rebuilds the index under one lock, refusing whatever would break the lint, `memory search` finds entities and orders by every word, and `memory index` rebuilds. `just memory-add`, `just memory-search` and `just memory-index` wrap them.
- A SessionStart hook gives Claude and Codex the same board and memory digest, under 9,000 characters and readable by the Python 3.9 macOS ships. The tracked `.codex/hooks.json` also carries the work-order hooks Codex ran from an untracked copy, so a checkout that had one moves it aside once before it pulls, and `just codex` starts Codex with `--add-dir` on the absolute board, the one place it may write outside the worktree; `board.py` names that flag when a write is refused. Camps get none of it. See `work/BOARD.md` and ADR 0018.
- Where Codex's SessionStart hook is off, `just codex` puts the board digest in front of the first prompt. A linked worktree runs the main checkout's `.codex/hooks.json` and inherits its trust, so the check keys on the main checkout's path and one approval in `/hooks` covers every worktree. The hook counts as on only when that file carries it and `/hooks` has it enabled with the trust hash Codex computes for it now, so an edited, turned-off or missing hook still gets the digest, and `just codex` names which in one line.
