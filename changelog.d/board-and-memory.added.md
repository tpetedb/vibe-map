- The board room and the shared memory for every agent session. `tools/board.py` reads and appends the room in the git common dir under a lock, with stable entry ids, checked-out and landed orders derived from `tools/work.py`, and explicit slots. `just board`, `just board-say`, `just board-slot` and `just memory-lint` wrap it. The official MCP memory server (pinned) is started for Claude from `.mcp.json` and for Codex from `.codex/config.toml`, with writes serialized across processes and the whole-graph read refused. A SessionStart hook gives both the same short board and memory digest. Camps get none of it. See `work/BOARD.md` and ADR 0018.
