# Obsidian notes

The vault is a folder of Markdown files. Obsidian conventions: https://help.obsidian.md/links

Rules:
- One note per topic, in `vault/Camp/<Topic>.md`. Title line `# <Topic>`.
- Link related notes with `[[Topic]]` wikilinks. Every new note links to at least two existing ones and is linked from `vault/Camp/Tonight.md`: add a dated bullet under `## Build log`.
- Date new entries: `## YYYY-MM-DD` sections, newest first.
- Tags at the bottom: `#workstream`, `#concept`, `#people`, `#decision`.
- Keep a "Sources" section: real URLs only, one per line.
- Hubs to link to: `Tonight`, `Evening 1` to `Evening 4`, `Resources`, `Your path`, and the eight workstream notes (Innovation Hub, Centre of Excellence, Data Warehouse, Business Continuity, Stakeholder Bridge, Knowledge Tree, Go-to-Market, Autonomous Operations), which `uv run vibe done` creates.
- `Map.md` is generated by the CLI; do not hand-edit it.

Template:

```
# <Topic>

<two-sentence summary>

## <YYYY-MM-DD>
- what was built or decided
- links: [[Related]], [[Related2]]

## Sources
- https://...

#concept
```

Check the result with `uv run vibe vault lint` (orphans and dead links). `uv run vibe vault build` rebuilds the generated notes and the map.
